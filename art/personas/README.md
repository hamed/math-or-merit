# Personas

Cartoon bust portraits for the essay's cast, in the cow's visual language
(see `art/cow/README.md`): essay ink-on-cream, tissue tints, three stroke
tiers, shared `0 0 300 300` space. All generated by `gen_personas.py`
(`python3 gen_personas.py` rewrites the four SVGs) — project-drawn from
public-domain reference photos, no external assets.

- `einstein.svg` — the physicist of the joke. Circle grammar: wild
  side-heavy hair cloud (unioned circle cluster), walrus mustache, heavy
  lids, tweed with texture dots.
- `mendeleev.svg` — the chemist. Chest-length scalloped beard (tapering
  unioned cluster), long swept-back side locks, pale focused squint,
  wide-lapelled light suit.
- `farmer.svg` — whose cow stopped giving milk (after the Robert Bakewell
  engraving): flat-topped wide-brim hat, side curls, jowls, buttoned coat.
- `musk.svg` — the spherical human, pre-sphere. Deliberately **rectangle
  grammar** — the cow is circles, he is rectangles — because the essay later
  strips him into the same circle the cow became (`PersonScene`).

Layering trick used throughout: hair/beard masses are circle clusters drawn
twice — a stroked pass then a fill-only pass — so the ink outline survives
only on the outer silhouette (`cluster()` in the generator).

Swapping the scene figures means re-anchoring their choreography (flask arm
pivot, arm-up gesture), so that's its own pass.
