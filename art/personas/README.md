characters, with small hints, minimal."*

The style that stands is the one already in the scenes: stick-figure-simple
bodies, ONE identifying hint each —

- physicist: the hair does the talking (CowScene);

Reference photos for hints live untracked in the owner's `inbox/`. Don't
rebuild detailed likenesses without an explicit ask.
